# MAC0122-Algorithm-development-principles

This repository is a curated collection of algorithms, exercises, and programming examples studied during MAC0122 — Principles of Algorithm Development.

The code was developed as part of the learning process for the course. Some implementations were written independently, while others were developed with guidance from the course instructors or adapted from examples and exercises presented in Algorithms by Robert Sedgewick and Kevin Wayne.

The purpose of this repository is to organize and document the main algorithmic ideas explored throughout the course rather than to present every implementation as original work.

Some files may include:

code developed during lectures or with instructor guidance;

adaptations of examples discussed in class;

implementations based on exercises or examples from Robert Sedgewick and Kevin Wayne's Algorithms;

modifications and extensions written as part of course assignments.

The repository is intended for educational and portfolio purposes, documenting the concepts and algorithms studied during the course.
